# ひろば掲示板

誰でも投稿でき、意見を交換できる掲示板の試作版です。投稿・返信・いいねでポイントがたまり、
レベル・バッジ・ランキングで「書きたくなる」仕組みを入れています。

## 使い方

`index.html` をブラウザで開くだけで動きます(ビルド・サーバー不要)。

## 主な特徴

- ホームからその場で投稿できる投稿欄(下書きの自動保存)
- 毎日変わる「今日のお題」と「今日のミッション」
- ポイント / レベル / バッジ / ランキング、レベルアップ演出
- ベストアンサー、通報、NGワード、管理者による非表示
- スマホは下タブ+中央の投稿ボタン、PCは右サイドバー。ダークモード対応

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の土台 |
| `style.css` | デザイン |
| `app.js` | 画面と操作 |
| `store.js` | データ層(現在は localStorage) |

## 試作版の制限

データはブラウザ内(localStorage)にだけ保存されるため、他の人の投稿は見えません。
共有の掲示板にするには Supabase / Firebase などのバックエンドが必要です。
仕様と今後の課題は [要件書.md](要件書.md) を参照してください。
