# ひろば掲示板

誰でも投稿でき、意見を交換できる掲示板です。投稿・返信・いいねでポイントがたまり、
レベル・バッジ・ランキングで「書きたくなる」仕組みを入れています。
データは [Supabase](https://supabase.com) に保存され、全員で共有されます。

## セットアップ

1. [supabase/セットアップ手順.md](supabase/セットアップ手順.md) に沿って Supabase のプロジェクトを作り、
   [supabase/schema.sql](supabase/schema.sql) を実行する
2. `config.js` に Project URL と anon(publishable)キーを書く
3. `index.html` をブラウザで開く(GitHub Pages などの静的ホスティングにそのまま置ける。ビルド不要)

`config.js` が未設定のときは、画面に案内が表示されます。

## 主な特徴

- ホームからその場で投稿できる投稿欄(下書きの自動保存)
- 毎日変わる「今日のお題」と「今日のミッション」
- メールアドレス+パスワードで登録・ログイン(確認メールで認証、パスワード再設定つき)
- マイページでニックネーム・パスワードの変更ができる
- ポイント / レベル / バッジ / ランキング、レベルアップ演出
- ベストアンサー、通報、NGワード、管理者による非表示
- スマホは下タブ+中央の投稿ボタン、PCは右サイドバー。ダークモード対応
- **ポイント計算・権限・NGワード判定はサーバー側**(SQL の関数)。ブラウザからは改ざんできない

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面の土台とデザイン |
| `app.js` | 画面と操作 |
| `store.js` | データ層(Supabase との通信) |
| `config.js` | Supabase の接続情報(公開してよい値のみ) |
| `supabase/schema.sql` | テーブル・関数・権限の定義(SQL Editor で実行) |
| `vendor/` | 同梱した外部ライブラリ(supabase-js) |

仕様と今後の課題は [要件書.md](要件書.md) を参照してください。
